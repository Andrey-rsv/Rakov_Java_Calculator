# Calculator — Java 21

Тестовое задание для стажировки QA Engineer Java.

## Описание
Проект представляет собой консольный калькулятор, реализующий базовые арифметические операции.

## Функционал
- Сложение, вычитание, умножение, деление
- Обработка исключения при делении на ноль

## Стек технологий
- Java 21
- JUnit 5
- Maven

## Инструкция по запуску
Для запуска программы выполните в терминале:
```bash
mvn compile exec:java
